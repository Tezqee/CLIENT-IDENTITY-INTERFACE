AGENT IDENTITY VAULT

Generate or load cryptographically secure agent keypairs locally in the browser.

ACTIVE VAULT STATUS

1. INITIALIZE NEW DID IDENTITY

Creates a new random Ed25519 keypair and encrypts it using PBKDF2 + AES-GCM.

2. LOAD ENCRYPTED VAULT FILE

Load an exported `agent-vault.json` vault file and supply the passphrase.

Migrating Between Terminal CLI and Web UI

To migrate your existing identity.pem key from the Python CLI into the Web UI (or vice-versa), you can run our translation utility inside your terminal: 

python vault_tool.py

This tool handles PKCS8 PEM decryption, extracts the secret seed, derives the DID multicodec, and outputs the AES-GCM encrypted Web UI format agent-vault.json securely, and vice-versa.
